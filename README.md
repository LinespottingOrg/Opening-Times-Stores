# Opening Times - Stores

Floating WinForms desktop widget: favorite stores, today's hours, specials, green sale alerts.

## Run

```
cd "C:\Users\User\Dropbox\aiprojekt\Microsoft Store APPS\Opening Times - Stores"
dotnet run --project OpeningTimesWidget
```

## Token (local only)

Right-click widget → **Set xAI token…**  
Stored in:

```
%LocalAppData%\OpeningTimesWidget\settings.json
```

Never commit tokens. Weekly xAI refresh (hourly check, 7-day gate).
