Privacy Policy — Opening Times - Stores

Publisher: Linespotting AB · Effective: 2026-09-21 · Product version 1.0.2
Platforms: Windows desktop · Android (Google Play package app.openingtimes) · iOS (when released)

Summary

Opening Times EU shows favourite store opening hours, optional specials, local sunrise/sunset, and (on Windows) today’s weather for your saved places. Core features work without a Linespotting account. There are no in-app purchases and no ads in the current versions.

Data stored on your device

  • All platforms: Favourite store list and hours cache on the device only.
  • Windows: Theme, sun-place settings, and optional xAI API token in local app data (%LocalAppData%\OpeningTimesWidget\). The token is never uploaded to Linespotting servers.
  • Android / iOS: Store list via on-device storage (AsyncStorage). No account sync.

Network requests

  • Windows — MET Norway / yr.no (api.met.no Locationforecast 2.0): weather for the places shown in the widget (default Stora Frö, Kalmar, Karleby). A User-Agent with contact email is sent as required by MET. Forecast JSON may be cached on the device. Temperature and symbols stay in the widget; the app does not open yr.no in a browser for normal use.
  • Windows — Open-Meteo (open-meteo.com): sunrise/sunset and optional place geocoding.
  • Windows — xAI (api.x.ai): only if you provide an API token and a weekly hours refresh runs.
  • Mobile builds do not call xAI, MET, or Open-Meteo in the current 1.0.0 release.

What we do not do

  • No advertising ID tracking in the app.
  • No sale of personal data.
  • No mandatory cloud account for core features.
  • No Google Play Billing / subscriptions in this app.
  • No analytics SDKs that identify you for advertising.

Children

The app is a utility for store hours. It is not directed at children under 13. We do not knowingly collect personal information from children.
